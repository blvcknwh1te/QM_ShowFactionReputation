[h1]Reputation on Mission Tooltip[/h1]

Показывает числовую репутацию игрока с фракцией отдельной строкой в mission tooltip (первая строка блока миссии при выборе контракта).

[b]Что делает[/b]
[list]
[*] Добавляет строку «Репутация» (ключ локализации tooltip.reputation) перед Миссия / Сложность / …
[*] Берёт значение из Faction.PlayerReputation
[*] Только UI / QoL - без правок геймплея, можно ставить и снимать
[/list]

[b]Совместимость[/b]
[list]
[*] Quasimorph 1.0
[*] Hard-зависимостей нет (Harmony уже в игре)
[/list]

[b]Исходники[/b]
https://github.com/blvcknwh1te/QM_ReputationOnMissionTooltip

[h1]Reputation on Mission Tooltip[/h1]

Shows the player's numeric reputation with each faction as its own row on the mission tooltip (first row of the mission block when picking a contract).

[b]What it does[/b]
[list]
[*] Adds a Reputation row (game locale key tooltip.reputation) above Mission / Difficulty / …
[*] Uses Faction.PlayerReputation
[*] UI-only QoL - no gameplay changes, safe to add/remove
[/list]

[b]Compatibility[/b]
[list]
[*] Quasimorph 1.0
[*] No hard dependencies (Harmony is already bundled with the game)
[/list]

[b]Source[/b]
https://github.com/blvcknwh1te/QM_ReputationOnMissionTooltip
