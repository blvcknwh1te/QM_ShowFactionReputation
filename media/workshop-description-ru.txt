[h1]Show Faction Reputation[/h1]

Показывает числовую репутацию игрока с фракцией в тултипе брифинга / выбора контракта (рядом с уровнем технологий).

[b]Что делает[/b]
[list]
[*] Дописывает репутацию в заголовок фракции (например: ТУ 3 · 12)
[*] Берёт значение из Faction.PlayerReputation
[*] Только UI / QoL — без правок геймплея, можно ставить и снимать
[/list]

[b]Совместимость[/b]
[list]
[*] Quasimorph 1.0
[*] Soft-совместим с модами на тот же тултип (например Show Tech Level) — этот мод применяется последним и дописывает к уже собранному тексту
[*] Hard-зависимостей нет (Harmony уже в игре)
[/list]
